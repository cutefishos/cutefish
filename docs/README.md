# Cutefish Documentation

Documentation for the Cutefish desktop.

- [Architecture](architecture.md): the processes, libraries and
  protocols that make up the desktop, and how a frame and an input event
  travel through them.
- [Building Cutefish from Source](building.md): build the desktop and
  install it on an existing Linux distribution.
- [Adding a Language](translating.md): translate Cutefish into a new
  language or correct an existing translation.
- [Design Rules](design-rules.md): layout rules for insets and scroll
  bars in rounded windows, panels and cards.
